Restart Console gives you multiple ways to integrate with external tools and automate your operations. Whether you want to trigger actions from your own backend, react to real-time system events, or query the API programmatically, the integration layer is built to fit your existing workflows without requiring custom middleware.

## What's available

Restart Console exposes three primary integration surfaces:

- **REST API** — A fully documented HTTP API that lets you create, manage, and monitor systems programmatically. Every action available in the console UI is also available via the API.
- **Webhooks** — Push-based event notifications delivered to your endpoint whenever something meaningful happens to a system, such as a state change or an error.
- **API Key Authentication** — Secure, scoped credentials you generate in the console and attach to every API or webhook verification request.

## How authentication works

Every request to the Restart Console API must include a valid API key in the `Authorization` header. API keys are scoped at creation time, so you can issue separate keys for read-only monitoring, full management access, or webhook signature verification. See the [API Keys](/integrations/api-keys) page for instructions on generating and rotating keys.

<Note>
  Webhook payloads are signed with a secret you configure per endpoint. Always verify the signature before processing a payload. See [Verifying webhook signatures](/integrations/webhooks#verifying-webhook-signatures) for details.
</Note>
